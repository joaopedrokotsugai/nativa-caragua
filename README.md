# Nativa Caraguá

Site de conscientização ambiental e apoio a campanhas e projetos de Caraguatatuba.

- **`Site/`**: front-end (React + Vite + Tailwind). Veja [`Site/README.md`](Site/README.md).
- **`backend/`** e **`database/`**: API e banco, feitos por outra pessoa. O que o front espera da API está em [`Site/API.md`](Site/API.md).

Para rodar o site, entre na pasta `Site` (é lá que fica o `package.json`):

```bash
cd Site
npm install
npm run dev
```
